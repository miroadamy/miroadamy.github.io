Useful tool for Dockerhub

2018-10-24
DevOps tools
187 words 1 min read

Skopeo

I have stumbled upon this tool: https://github.com/containers/skopeo - command line tools for manipulation with Docker images and Docker image registries.

It can work with OCI images as well as the original Docker v2 images.

Installation

brew install skopeo

Usage
